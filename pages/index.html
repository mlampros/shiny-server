Shiny applications

Interactive R / Shiny demos that run entirely in your browser (Shinylive, WebAssembly). No server and no login.

Geocoding

Address to coordinates using the OpenStreetMap Nominatim service, shown on a Leaflet map.

Reverse geocoding

Coordinates to address using OpenStreetMap Nominatim and Leaflet.

GeoJSON viewer

Display a GeoJSON object or a GeoJSON url on a map using the geojsonR package and Leaflet.

String matching

Compare strings with Levenshtein distance, fuzzy WRatio and string similarity.

The first visit can take 10 to 30 seconds, because R (webR) and the R packages are downloaded to the browser. Later visits are faster.
Source code: github.com/mlampros/shiny-server
